# Lumen Roast — 3D deals & checkout demo

A local demo of a 3D product page: sign in, pick a **coffee sampler** deal, then complete a fake checkout. Nothing is stored or charged.

## Run it

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 5173
```

Then visit http://127.0.0.1:5173
